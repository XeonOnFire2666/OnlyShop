# OnlyShop — магазин одежды внутри Telegram

**🌐 Язык:** [English](README.md) · **Русский**

> **Статус:** демо для портфолио. Проект не запускался коммерчески — это рабочее решение реальной бизнес-проблемы малого магазина, собранное как законченный продукт.

**OnlyShop** — Telegram Mini App, в котором клиент сам выбирает вещь, размер, кладёт в корзину и оформляет заявку. Менеджеру приходит готовый заказ прямо в Telegram, с кнопками управления статусом.

В комплекте: мини-приложение для клиентов, веб-админка и Telegram-бот для менеджеров.

---

## Какую проблему решает

Небольшие магазины в Telegram обычно продают через личные сообщения. Выглядит это так:

> — Здравствуйте, а это есть в наличии?
> — Какой размер остался?
> — А другие цвета есть?
> — Как оплатить?

Каждая такая переписка — это время менеджера и шанс потерять клиента: человек устаёт ждать ответа и уходит. Менеджер при этом отвечает на одни и те же вопросы по кругу.

**OnlyShop убирает переписку из воронки продаж:**

| Было (переписка в личке) | Стало (OnlyShop) |
|---|---|
| «Есть ли размер M?» — ждать ответа | Клиент сам видит актуальные размеры и остатки |
| Менеджер вручную записывает заказ | Заявка оформляется в корзине за пару касаний |
| Данные клиента приходится выяснять в диалоге | Имя, телефон, адрес и способ доставки собираются в форме |
| Заказы теряются в потоке сообщений | Каждый заказ — отдельное уведомление с историей статусов |

**Итог:** выше конверсия (клиент доходит до заказа без ожидания ответа), меньше рутины у менеджера, нет потерянных заявок.

Ключевая идея: **малый магазин принимает заказы через корзину и заявку внутри Telegram вместо переписки в личке.**

## Как это работает

1. Клиент открывает Mini App из бота и листает каталог.
2. Открывает карточку товара, выбирает размер, добавляет в корзину.
3. Оформляет заявку: контакты, доставка (курьер или самовывоз), способ оплаты, комментарий.
4. **Менеджеру в Telegram приходит уведомление о новом заказе** с составом, суммой, данными клиента и кнопками смены статуса.
5. Если оплата онлайн, клиент отправляет боту скриншот чека. Бот пересылает его менеджерам с кнопками «Подтвердить» / «Отклонить».
6. Менеджер ведёт заказ по статусам, клиент получает уведомления об изменениях.

### Жизненный цикл заказа

```
Ожидает подтверждения → Принят → Оплачен → В пути → Завершён
          └──────────────┴────────┴──→ Отменён
```

Допустимые переходы закреплены в доменной модели (`Order.CanTransitionTo`), недопустимые отклоняются. При отмене остатки возвращаются на склад, а списанные бонусы — клиенту.

## Возможности

### Клиентское Mini App
- Каталог с категориями и поиском
- Карточка товара: галерея фото, выбор размера с учётом остатков, состояние вещи, бренд
- Корзина, оформление заявки, история заказов, отмена заказа
- Избранное
- Переключение валют (BYN / RUB)
- Бонусная программа: начисление за завершённые заказы, возможность потратить бонусы
- Предзаказы (presale) с датой закрытия приёма
- Связь с менеджером, информация о доставке
- Интерфейс с аккуратным дизайном и плавными анимациями, хаптик-отклик Telegram, нативная кнопка «Назад»

### Админка (`/admin`)
- Товары: создание, редактирование, фото, цены, публикация и архив
- **Размеры и остатки**: варианты товара по размерам, корректировка склада
- Заказы: фильтры, просмотр, смена статуса
- Категории, точки предзаказа, сотрудники
- Роли `Admin` и `Manager`
- Привязка Telegram-аккаунта сотрудника через одноразовую ссылку

### Telegram-бот для менеджеров
- Уведомление о новом заказе, которое обновляется при смене статуса
- Inline-кнопки: ✅ Принять · 💳 Оплачен · 🚚 В пути · 🏁 Завершён · ❌ Отменить
- Приём скриншотов оплаты и подтверждение чека в один клик
- Работает через webhook

## Технологии

| Слой | Стек |
|---|---|
| Бэкенд | C# / ASP.NET Core (.NET 10), Minimal API |
| База данных | PostgreSQL, Entity Framework Core (миграции применяются при старте) |
| Клиентское Mini App | React 18 + htm (без сборки), Telegram WebApp SDK |
| Админка | React 18, React Router, Vite |
| Telegram | Telegram.Bot, webhook |
| Аутентификация | Mini App: проверка подписи Telegram `initData`; админка: JWT |
| Хранение фото | S3-совместимое хранилище (AWS SDK) |
| Деплой | Docker (multi-stage) |

### Архитектура

Бэкенд построен по слоям (Clean Architecture):

```
OnlyShop.Core            — сущности, enum'ы, доменные правила (Order, Product, ProductVariant…)
OnlyShop.Application     — сервисы, DTO, интерфейсы репозиториев, бизнес-логика заказов
OnlyShop.Infrastructure  — EF Core, PostgreSQL, S3, JWT, Telegram-клиент
OnlyShop.Adapters        — HTTP-эндпоинты, Telegram webhook, обработчик бота
OnlyShop                 — точка входа, статика (Mini App и админка), Dockerfile
```

Зависимости направлены внутрь: доменный слой ничего не знает об инфраструктуре.

## Запуск локально

**Требования:** .NET 10 SDK, PostgreSQL, Node.js (для админки), Telegram-бот от @BotFather.

1. Склонируйте репозиторий и настройте конфигурацию (например, через user-secrets или `appsettings.Development.json`):

   | Секция | Назначение |
   |---|---|
   | `ConnectionStrings:Default` | подключение к PostgreSQL |
   | `Jwt` (`Issuer`, `Audience`, `Key`) | токены админки |
   | `Telegram:BotToken` | токен бота |
   | `TelegramWebhook` (`PublicBaseUrl`, `SecretToken`, `MiniAppUrl`, `BotUsername`) | webhook и ссылка на Mini App |
   | `FileStorage` (`S3Endpoint`, `S3AccessKey`, `S3SecretKey`, `S3BucketName`, `S3Region`) | хранилище фото |
   | `Bonus` (`AccrualPercent`, `MaxSpendPercent`) | бонусная программа (по умолчанию 5% / 30%) |

2. Запустите бэкенд (миграции применятся автоматически):

   ```bash
   dotnet run --project OnlyShop
   ```

   Сервис слушает `http://0.0.0.0:5201`.

3. Админка в режиме разработки:

   ```bash
   cd OnlyShop/AdminApp
   npm install
   npm run dev      # http://localhost:5174, /api проксируется на бэкенд
   ```

   Продакшен-сборка (`npm run build`) попадает в `OnlyShop/wwwroot/admin` и раздаётся самим бэкендом по адресу `/admin`.

4. Mini App: откройте `/` внутри Telegram. Вне Telegram (или с параметром `?mock`) приложение работает на мок-данных, так что интерфейс можно посмотреть без бота.

### Docker

```bash
docker build -t onlyshop .
docker run -p 8080:8080 onlyshop   # плюс переменные окружения для конфигурации
```
